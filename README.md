# Wine Festival Schedule

A responsive-style HTML table layout for an annual family wine festival, developed as part of the **Codecademy Front-End Engineer Career Path**.

## Project Overview

The Wine Festival Schedule is a beginner front-end development project designed to display a structured event schedule using semantic HTML tables.

The webpage presents five scheduled events, including their times and descriptions, in a clean, organized layout.

The primary objective was to practice building HTML tables, organizing tabular information, and understanding how HTML and CSS work together to present content.

## Technologies Used

- **HTML5** — Page structure, semantic elements, and table organization
- **CSS3** — Visual styling and layout using Codecademy's provided stylesheets
- **Git** — Local version control
- **GitHub** — Repository hosting and source code management
- **Visual Studio Code** — Local development environment

## Features

- Structured festival schedule with five events
- Table headings for event times and names
- Table organization using `<thead>` and `<tbody>`
- Column spanning using the `colspan` attribute
- CSS classes for targeted styling
- Styled page header and footer

## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Kbuck2290/wine-festival-schedule.git
   ```

2. Navigate into the project directory:

   ```bash
   cd wine-festival-schedule
   ```

3. Open `index.html` in your preferred web browser.

No additional dependencies or installation steps are required. An internet connection may be needed to load the Google Fonts stylesheet.
